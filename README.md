# Python-DA-Capstone-Project
The project involves analysing Social media Engagement Analytics using Python with visualizations.
##Project Overview:
This project analyzes Social media engagement data using Python to understand User behaviour,enaggement patterns and Sentiment Trends.
The analysis covers data cleaning, transformation, statistical analysis, exploratory data analysis (EDA), and visualization using NumPy, Pandas, Matplotlib, Seaborn, and Plotly.

##Objectives:
*Clean and prepare the raw dataset for analysis
*Handle missing and duplicate values
*Correct data types and standardize categorical values
*Explore numerical and categorical variables
*Analyze relationships between engagement metrics
*Perform descriptive statistical analysis
*Create visualizations to communicate findings

Tools & Technologies
*Python
*NumPy – Numerical operations
*Pandas – Data manipulation and analysis
*Matplotlib – Basic data visualization
*Seaborn – Statistical visualizations
*Plotly – Interactive visualizations
*Jupyter Notebook / Google Colab

##Project Workflow:
1.Data Cleanining:
*Detected missing values using isnull() and isna()
*Handled missing values using appropriate methods such as median and mode
*Identified and removed duplicate records
*Standardized categorical values
*Extracted hashtag counts,Cleaned sentiment labels
2.Exploratory Data Analysis:
*head(),tail(),shape,columns,info(),dtypes,describe(),value_counts(),unique(),nunique(),groupby()
A correlation matrix was also created to examine relationships between numerical variables.
3. Data Wrangling:
Used groupby() to analyze:
*Post type,Country,Sentiment,Post category
*Applied transformations to support further analysis
4. Statistical Analysis
Descriptive statistics were calculated for:
*Likes,Comments,Shares,Watch time,Engagement rate,Followers
The analysis included:
*Mean,Median,Mode,Standard deviation,Variance,Percentiles

##Data Visualizations
*Matplotlib:
1.Scatter Plot: Likes vs Impressions
2.Line Chart: Daily Engagement Trend
3.Pie Chart: Gender Distribution
4.Histogram: Age Distribution
5.Box Plot: Engagement Rate Distribution
*Seaborn:
1.Count Plot: Post Type
2.Violin Plot: Followers vs Sentiment
3.Heatmap: Correlation Matrix
4.Swarm Plot: Engagement vs Device
*Plotly:Interactive Visualization: Interactive Bar chart  for exploring  different categroy of posts

##Key Insights:
The project uses statistical summaries and visualizations to identify patterns in social media engagement.
Some of insights generated include are:
*Comparison of average engagement across different post types and categories
*Relationship between age and engagement rate
*Comparison of verified and non-verified account performance
*Differences in follower distribution across sentiment categories
*Distribution and potential outliers in engagement rate
*Relationships among numerical engagement metrics using correlation analysis

##Conclusion:
This project demonstrates the use of Python-based data analytics techniques to clean, explore, analyze, and visualize social media engagement data. The analysis helps identify patterns in content performance, user behavior, engagement metrics and sentiment by providing a practical example of an end-to-end data analysis workflow.
